# Project Context

This folder captures lightweight, repo-local documentation for the current state of the codebase.

Files:

- `code-architecture.md`: the implemented architecture, stack, boundaries, and intended extension points.
- `current-stage.md`: a time-stamped snapshot of the repository's current delivery stage and git hygiene state.

Guidelines:

- Treat these files as living documentation.
- Update them when the app gains real routes, API handlers, shared domain logic, or a second service.
- Prefer documenting implemented behavior separately from planned behavior.
